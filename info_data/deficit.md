# This is a guide file on where to download the inflation data and how to process it, in order to be use in the app.

## Download

**balance mensual**: Go to this [page](https://www.minhacienda.gov.co/politica-fiscal/cifras-de-politica-fiscal/gobierno-nacional-central/balance), scroll down at the bottom of the chart (beneath it) and download the file "Balance Fiscal GNC (mensual y trimestral)" and store it at:
```bash
/path/to/the/repo/colombia/data/original/hacienda/deficit/balance_mensual.xlsx
```

**balance anual**: Go to this [page](https://www.minhacienda.gov.co/politica-fiscal/cifras-de-politica-fiscal/gobierno-nacional-central/balance), scroll down at the bottom of the chart (beneath it) and download the file "Balance Gobierno Nacional Central" and store it at:
```bash
/home/riosandres/Documents/coding/genius/colombia/data/original/hacienda/deficit/balance_anual.xlsx
```
