# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Running the App

```bash
streamlit run app.py
```

The app can be run from anywhere — data paths are absolute, anchored on `BASE_DIR` (`generalities/function.py`, resolves to the repo root). Exception: the `clean_data/*` scripts use relative data paths, so where you run them matters and splits into two groups:

- Most scripts use `../data` and import nothing from the repo — run them from inside `clean_data/` (e.g. `cd clean_data && python clean_borns.py`). This covers `clean_borns.py`, `inflation_clean.py`, `net_migration.py`, `migration_clean.py`, `annual_growth_clean.py`, `quarter_growth_clean.py`. `population_clean.py` takes one positional arg — `python population_clean.py nacional|departamental|municipal` — and writes one CSV per category.
- `clean_deaths.py` and `clean_laboral_market.py` use `./data` and `from generalities...` — run them as a module from the repo root: `python -m clean_data.clean_laboral_market`.

## Architecture

Multi-page Streamlit app displaying Colombian statistics. Entry point is `app.py` (homepage); pages live in `pages/`. Two domain pages: **Macroeconomics** (GDP/CPI) and **Demography** (population, migration, births, deaths). Each page mirrors the same layout: a page-entry script in `pages/`, tab modules under `pages/tabs/<domain>/`, data helpers under `pages/helpers/<domain>/`, and config dicts under `generalities/<domain>_generalities/`.

**Data flow:**
1. CSVs in `data/` → read by page/tab files → cleaned/pivoted by the per-domain helpers (`pages/helpers/macro/` for `gdp_functions.py`/`cpi_functions.py`; `pages/helpers/demography/` for `births_functions.py`/`deaths_functions.py`/`migration_functions.py`/`population_functions.py`) → charted by `pages/helpers/macro/macro_charts.py` (generic builders, shared) and `pages/helpers/demography/demography_charts.py` (population-only builders)
2. Raw data comes from four sources: **DANE** (National Statistics Dept), **Banco de la República** (Central Bank), **World Bank** (net migration), and **Migración Colombia** (inbound/outbound travelers, stored under `datos_abiertos/`)

**Key modules:**
- `pages/Macroeconomics.py` — page entry point, loads data, sidebar radio selects section (GDP/CPI), delegates to renderers
- `pages/tabs/macroeconomics/gdp.py` — GDP tab logic: Levels vs Growth. **Levels** uses method/perspective/category selectors, sidebar filters. **Growth** has a `Source` selector (Spend / Production / Income), a sidebar `Variable` picker (defaults to "Gross Domestic Product"), `Chart` (Line/Bar), and a `Growth` mode of Annual / Annual per Quarter / **Quarter over Quarter**. The Banco-de-la-República spliced series (base 2015) is used only for the GDP total in Spend/Production (`use_banco`); other variables derive growth from the DANE level CSVs via `mf.variable_growth`/`mf.quarter_over_quarter`. Income is nominal (current-prices caption). Path consts `PRODUCTION_PATH`, `INCOME_PATH`, `SPEND_BASE_PATH`. Imports `gdp_functions as mf` + macro_charts
- `pages/tabs/macroeconomics/cpi.py` — CPI tab logic: method/perspective/category selectors, sidebar filters; path consts `CPI_15_PATH`/`CPI_20_PATH` (15- vs 20-core-item baskets), `CITY_BASE` (per-city CPI dir), `CAT_BASE` (per-spend-category dir). Imports `cpi_functions as mf` + macro_charts
- `pages/Demography.py` — page entry point: loads `data/dane/population/nacional.csv`, sidebar **View** radio (`generalities/demography_generalities/migration.VIEW = ["National", "Department", "Municipality", "Migration", "Births", "Deaths"]`) dispatches to the six `render_*` functions in `pages/tabs/demography/`. National-population data comes from DANE (`data/dane/population/*.csv`, sex×single-age, projected past `PREV_YEAR = current year - 1`), not Banco de la República; projected years (`> PREV_YEAR`) render dashed (`dc.projection_line`) and carry a `PROJECTED_NOTE` caption.
- `pages/tabs/demography/` — one module per view (the old single `population.py` was split here), each exposing a `render_*` entry; cross-view helpers + `PROJECTED_NOTE` live in `_shared.py`. All import the shared generic charts as `mc` (`pages/helpers/macro/macro_charts`) and the population-only charts as `dc` (`pages/helpers/demography/demography_charts`):
  - `national.py` (`render_national`, `_render_population_projection`): **Method** selector Total / Growth / Projection / By Age. Total perspectives are National / Net Migration / Births / Deaths; Growth is year-over-year `diff`/`pct_change` (Absolute/Percentage) on `pop.national_total_series`. Projection is the full DANE series solid-then-dashed; By Age calls the shared `_render_pyramid` (Colombia population pyramid). Optional "Compare with Births / Net Migration / Deaths" overlays (Growth+Absolute); in Total mode the Births and Deaths perspectives expose a one-way "Compare with Deaths"/"Compare with Births" overlay; single-year selection renders a gauge `dc.indicator`. `show_all_applies` gates the "Show all years"/pre-2000 logic to non-DANE series. `NET_MIGRATION_PATH` const lives here
  - `department.py` (`render_department`) / `municipality.py` (`render_municipality`): from `POP_PATHS["departmental"]`/`["municipal"]` via `pop.dept_normalize`. **Chart Type** Map / Line / Bar / Population pyramid (Municipality has no Map). Gender (Total/Men/Women) and single-year Age (`AGE_SINGLE`, All ages + 0..100) selectors; Map is a `dc.colombia_choropleth`, Line uses `dc.projection_line` (dashed projection), Bar/pyramid as usual. A "Show projected" checkbox gates years `> PREV_YEAR`; selecting a future year without it `st.stop()`s with a warning. The shared `_shared._render_pop_geo_chart` is the chart dispatcher (handles president comparison via `reshape_by_presidents`); `_shared._render_pyramid` draws the pyramid
  - `migration.py` (`render_migration`, `_render_map`, `_render_line_bar`): chart types Map / Line / Bar; "Compare by" Countries / Direction / Gender / Year; Map is a `dc.choropleth_map` by country. `MIGRATION_PATH` const lives here
  - `births.py` (`render_births`, `_render_births_breakdown`/`_render_births_department`/`_render_births_municipality`): "Compare by" Gender / Mother Age / Education / Department / Municipality. Gender exposes a "Mother age" selector (All ages → `births_gender_pivot`; a specific age → `births_gender_age_pivot`); Mother Age exposes a Gender (Total/Boys/Girls) selector feeding `births_age_pivot`. Department supports a Colombia choropleth (geojson); Municipality drills down within a department; totals use a ranked horizontal bar via the shared `_shared._render_geo_bar_line`
  - `deaths.py` (`render_deaths`, plus `_render_deaths_breakdown`/`_deaths_dept_source`/`_render_deaths_department`/`_render_deaths_top_causes`/`_render_deaths_cause_compare`): "Compare by" Gender / Age Group / Area / Department / Cause (Top 5) / Cause (Compare). Gender comes from `total.csv`; Age Group and Area come from `area_grupo_edad.csv` (2008+). Age Group adds Gender (Total/Men/Women) and a **Cause** filter (All causes → `area_grupo_edad.csv` via `deaths_age_pivot`; a specific cause → dept×cause CSV via `deaths_age_cause_pivot`); Area adds Gender, Age-group, and Area sub-filters (`deaths_area_pivot(age_label, gender, area)`). Department, both Cause modes, and the choropleth come from the dept×cause CSVs (2019+) behind an **Occurrence/Residence** "Place" selector. Department reuses `bir.births_department_data`/`bir.births_geo_trend` (dept frame is `TOTAL NACIONAL`-filtered and `Fecha`→`year`-renamed) and adds a **Cause** filter; Cause (Top 5) is a ranked bar of the top causes for the active filters; Cause (Compare) charts ≤5 user-picked causes. Department and both Cause modes expose an **Age** filter that combines with Gender (Department age applies in Map and Line/Bar); since the dept×cause CSVs store age as `<age>_<gender>` columns, `deaths_age_gender_value` resolves the (gender, age) selection into a `_val` Series fed to the dept/cause pivots as `value_col`. To avoid sidebar overflow these views render the Department/Gender/Age selectors in a main-area `st.columns` row (the Age Group breakdown likewise moves Gender + Age-groups up)
- `pages/helpers/macro/` — macro data cleaning/pivoting (the old single `macro_functions.py` was split here by the structure refactor):
  - `gdp_functions.py` — `clean_gdp`, `clean_annual_growth`, sidebar/filter logic `generalities_spend_product`, and GDP growth builders (`_variable_levels` — pulls a Concepto's level series; `quarter_over_quarter` — `pct_change` quarter-on-quarter; `variable_growth` — annual `pct_change` over summed quarters or year-on-year `pct_change(4)`). Imports `PREV_YEAR` from `generalities.function` for per-capita GDP (excludes projected population years)
  - `cpi_functions.py` — `build_yearly_table`, `cpi_sidebar_filters`, `build_cpi_series`, `build_comparison_series`
- `pages/helpers/demography/` — demography data cleaning/pivoting:
  - `migration_functions.py` — `build_migration_map_data`, `migration_countries_pivot`, `migration_single_pivot`, `migration_year_pivot`
  - `births_functions.py` — `births_national_series`, `births_gender_pivot`, `births_gender_age_pivot`, `births_age_pivot` (optional `gender`), `births_education_pivot`, `births_department_data`, `births_geo_trend`
  - `population_functions.py` — `pop_value` (resolves a (gender, age) selection to a population column: `GENDER_AGG[gender]` for "All ages", else `<GENDER_PREFIX>_<age>`), `national_total_series` (year-indexed, optional `cap` year), `dept_normalize` (zero-pads the `DP` code, picks one canonical `Name` per code collapsing accent/spelling variants), `dept_map_data` (one value per dept for the choropleth), `geo_trend` (year×entity pivot over the full range so projection shows), `pyramid_rows` (sums single-age `Hombres_n`/`Mujeres_n` columns into 5-year buckets → men/women Series)
  - `deaths_functions.py` — `_cause_label` (strips leading NNN code, maps Spanish→English via accent-stripped `norm`), `deaths_dept_prepared` (`@st.cache_data` loader: drops `total nacional`, derives `Name` from the dept column, adds a `cause` label), `_dept_filter` (year/president/dept-name filter), `deaths_national_series`, `deaths_gender_pivot`, `deaths_gender_cause_pivot`, `deaths_area_pivot` (`age_label`/`gender`/`area`), `deaths_age_pivot`, `deaths_age_cause_pivot`, `deaths_top_causes`, `deaths_cause_pivot`, `deaths_cause_names`, `deaths_age_gender_value` (sums the `<age>_<gender>` dept columns for a (gender, age) combo); dept-based ones reuse the births geo helpers
  - `demography_charts.py` — population-only Plotly builders (imported as `dc`): `indicator` — gauge; `choropleth_map` — country-name choropleth; `colombia_choropleth` — geojson choropleth keyed on DANE dept code; `projection_line` — line where each series is solid up to `split_year` and dashed after (projected years); `population_pyramid` — diverging horizontal bars, men left/negative, women right
- `pages/helpers/macro/macro_charts.py` — shared generic Plotly builders (imported as `mc` by both pages): `line_chart`, `bar_chart` — generic, take `info` list for titles/axis labels and an optional `highlight` arg that greys non-selected series; both cap at the **first 6 series** (with a warning) when given a wider DataFrame; `line_or_bar` — dispatches to `line_chart`/`bar_chart`/`ranked_bar_chart` by `chart_type`; `ranked_bar_chart` — horizontal; `render_chart` — shared `st.plotly_chart` wrapper; `gdp_growth` — takes `title`/`chart_type`, single-year selection renders gauge indicator instead of line/bar chart
- `generalities/macro_generalities/` — macro config dicts (Spanish CSV column → English display label); `dictionaries.py` has filter UI dicts (presidents, months) — **shared by both pages**; `inflation.py` has CPI perspective name mappings and `spend_category_names`; `gdp_spend.py`/`gdp_production.py`/`gdp_income.py` hold the per-perspective Concepto→English term dicts
- `generalities/demography_generalities/` — demography config dicts; `migration.py` has `COUNTRY_EN` (Spanish→English country names), `COL_MAP` ((direction, metric)→CSV column), `METRIC_LABEL`, `VIEW`; `births.py` has `BIRTHS_PATHS`, `BIRTHS_COMPARE`, `GENDER_EN`, `AGE_EN`, `EDU_EN`, plus `DEPT_GEOJSON_PATH`/`DEPT_FEATURE_KEY`; `deaths.py` has `DEATHS_PATHS`, `DEATHS_COMPARE`, `GENDER_EN`, `AREA_EN`, `AGE_EN` (both Spanish typo spellings map to one label), `CAUSE_EN` (keyed on `norm`'d accent-stripped Spanish cause → English; collapses accent-variant duplicate causes), reusing births' `DEPT_GEOJSON_PATH`/`DEPT_FEATURE_KEY`; `population.py` has `POP_PATHS` (national/departmental/municipal CSVs), `GENDER_AGG` (gender→aggregate column), `GENDER_PREFIX` (gender→per-age column prefix), `AGE_SINGLE` (All ages + 0..100), `PYRAMID_GROUPS` (5-year buckets), and re-exports `PREV_YEAR` from `generalities.function`
- `generalities/function.py` — shared helpers used by both pages (stays at `generalities/`): `PREV_YEAR` (current year − 1, last observed year before projections — lives here so macro's per-capita GDP can use it without depending on demography); path/loading (`BASE_DIR`, `load_csv`/`load_geojson` both `@st.cache_data`, `to_datatime`), `norm` (accent-strip + lowercase for cause matching), `cap_series` (limit a DataFrame to N columns), lookups (`get_valid_presidents`, `find_key_by_value`), president filtering (`president_multiselect`, `reshape_by_presidents`, `show_all_years` — optional `return_flag` returns `(df, show_all)` so callers can read the checkbox state), and `highlight_selectbox` (shared sidebar "Highlight variable:" picker reused by gdp/cpi/migration/births/deaths — returns the chosen series name or None; optional `display_names` for label-mapped columns)
- `clean_data/` — one-off scripts for transforming raw Excel/CSV source files into the cleaned CSVs in `data/`; `clean_borns.py` decrypts password-protected `.xls` workbooks via LibreOffice (`soffice --headless --convert-to xlsx`); `clean_deaths.py` parses DANE death workbooks positionally (with a header guard `check_groups`) into the four `data/dane/deaths/` CSVs; `clean_laboral_market.py` parses multi-block DANE labor workbooks positionally (anchors on `Concepto` rows, infers header families via `classify`, normalizes period labels with `normalize_period`, reads bold col-0 rows from `.xlsx` for group headers) into long-format `data/dane/laboral_market/` CSVs (`Fecha, <dim>, Sexo, Grupo, Concepto, Periodo, Valor`, single-value columns dropped by `drop_dead_columns`) — **data/cleaning only, no UI tab yet**; `population_clean.py` takes one category arg (`nacional`/`departamental`/`municipal`), reads the right sheet from each year-span workbook, harmonizes the two divergent DANE schemas (pre-2018 `Hombres_0`/`Total Hombres` single-row header vs 2018+ `Hombres 0 años`/aggregate-`Hombres` two-row header) into old-style columns via `read_old`/`read_new`, keeps `ÁREA GEOGRÁFICA == "Total"` rows, concatenates year-spans, and writes one `data/dane/population/<category>.csv` — **data/cleaning only, no UI tab yet**

**Data directory layout:**
```
data/
  dane/GDP/{spend,production,income}/   ← DANE quarterly GDP tables (columns = year-quarter, rows = concepts)
  dane/borns/                           ← births_total.csv + births_by_{department,municipality,mother_age,education}.csv (DANE)
  dane/deaths/                          ← total.csv + area_grupo_edad.csv (2008+) + departamento_{muerte,residencia}.csv (dept×cause, 2019+) (DANE)
  dane/geo/                             ← colombia_departments.geojson (dept choropleth)
  dane/laboral_market/{Mercado Laboral,Departamentos,informalidad,regiones,infantil}/
                                        ← DANE labor-market tables, long format (cleaned by clean_data/clean_laboral_market.py); no UI yet
  dane/population/                      ← nacional.csv + departamental.csv + municipal.csv (DANE projections by sex×age, Total-area rows; cleaned by clean_data/population_clean.py); backs the Demography National/Department/Municipality views
  banco_republica/GDP/                  ← annual_growth.csv, quarter_growth.csv
  banco_republica/CPI/                  ← inflacion_15.csv + inflacion_20.csv (15- vs 20-core-item baskets) + city/ (per-city CPI) + spend_category/ (per-category)
  banco_republica/unemployment/         ← unemployment.csv
  world_bank/net_migration.csv          ← annual net migration
  datos_abiertos/migration.csv          ← Migración Colombia inbound/outbound by country (cleaned by clean_data/migration_clean.py from original/datos_abiertos/ entradas+salidas CSVs)
  original/dane/borns/*.xls(x)          ← raw DANE births workbooks (cleaned by clean_data/clean_borns.py)
  original/dane/deaths/*.xls(x)         ← raw DANE deaths workbooks by year (cleaned by clean_data/clean_deaths.py)
  original/dane/laboral_market/*.xls(x) ← raw DANE labor workbooks (cleaned by clean_data/clean_laboral_market.py)
  original/dane/population/{nacional,departamental,municipal}/*.xlsx
                                        ← raw DANE population projection workbooks by year-span (cleaned by clean_data/population_clean.py)
```

**Translation pattern:** Each GDP perspective has a matching dict in `generalities/macro_generalities/gdp_spend.py` (or `gdp_production.py`, `gdp_income.py`). The dict key is the Spanish `Concepto` value in the CSV; the value is the English label shown in the UI. `gdp.py` dynamically resolves which dict to use via `getattr(t, f"spend_{file}_terms", None)`.

**President filter:** `presidents` dict maps name → list of years (integers); `get_valid_presidents` intersects the data's year range with these. The UI is now a multiselect (`president_multiselect`): selecting one president filters years to `presidents[name]`; selecting two or more enters **comparison mode**, where `reshape_by_presidents` (`generalities/function.py`) re-indexes data to a relative "Term Year" axis and emits one column per variable×president. Used across Macroeconomics (GDP, CPI) and Demography (National/Department/Municipality/Migration/Births/Deaths).
