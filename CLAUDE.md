# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Running the App

```bash
streamlit run Homepage.py
```

The app can be run from anywhere — data paths are absolute, anchored on `BASE_DIR` (`generalities/function.py`, resolves to the repo root). Exception: the `clean_data/*` scripts use relative data paths, so where you run them matters and splits into two groups:

- Most scripts use `../data` and import nothing from the repo — run them from inside `clean_data/` (e.g. `cd clean_data && python clean_borns.py`). This covers `clean_borns.py`, `inflation_clean.py`, `net_migration.py`, `migration_clean.py`, `clean_productivity.py`, `clean_debt.py`, `clean_poverty.py`, `clean_deficit.py`. `population_clean.py` takes one positional arg — `python population_clean.py nacional|departamental|municipal` — and writes one CSV per category. `annual_growth_clean.py` was removed — its output (`annual_growth.csv`) was replaced by the manually-prepared `real_annual.csv`/`nominal_annual.csv`.
- `clean_deaths.py` and `clean_job_market.py` use `./data` and `from generalities...` — run them as a module from the repo root: `python -m clean_data.clean_job_market`.

## Architecture

Multi-page Streamlit app displaying Colombian statistics. Entry point is `Homepage.py` (homepage); pages live in `pages/`. Four domain pages: **Macroeconomics** (GDP/CPI/Job Market/Productivity/Debt/Deficit/ISE), **Demography** (population, migration, births, deaths), **Miscellaneous** (Exchange Rate, Monetary Policy Rate, Minimum Wage), and **Poverty** (Indicators, Household Profile, By Sex). Each page mirrors the same layout: a page-entry script in `pages/`, tab modules under `pages/tabs/<domain>/`, data helpers under `pages/helpers/<domain>/`, and config dicts under `generalities/<domain>_generalities/`. All five entry points (`Homepage.py` + the four `pages/*.py`) call `st.logo(BASE_DIR / "logo/logo.svg", size="medium")` for the sidebar logo and `st.image(BASE_DIR / "logo/logo_text.svg", width=300)` in place of the old `st.title("Statistics on Colombia")` header. `.streamlit/config.toml` holds the light/dark theme palettes (primary/background/text/border colors).

`Homepage.py` builds a KPI-card dashboard: it loads the latest value (+ prior-period delta + a 12-point sparkline trend) for each headline series directly from the same data helpers the domain pages use (GDP, CPI, Unemployment, ISE, Exchange Rate, Monetary Policy Rate, Fiscal Deficit, Debt-as-%-of-GDP, Debt Indicators, Productivity, Minimum Wage, Population, Births, Deaths, Net Migration, Monetary Poverty, Extreme Poverty, Gini, Misery Index), packs each into a `cfg` dict (`title, value, delta_text, delta_good, metadata, accent, spark`), and renders them via `pages/helpers/kpi_cards.py` — `render_kpi_card` (one card: title, big value, colored delta pill, caption, sparkline), `render_kpi_grid` (cards in rows of `per_row`), and `render_section` (a `st.expander` grouping cards under a title/description, with an optional `st.page_link` to the full domain page) — grouped into five sections: Headline Indicators (expanded by default, now includes the Misery Index card — `misery_cfg`, built from the same `rf.misery_index_annual` used by the Misery Rate tab, sourced from Seasonally Adjusted Unemployment + CPI + Lending Rate + `gdp_per_capita_growth`), Economic Indicators, Public Finance (Fiscal Deficit — `fiscal_deficit_cfg`, the Total Deficit/Surplus row of `data/hacienda/deficit/anual/balance_pib.csv` via `dff.load_deficit`, `delta_good` inverted since the series is negative for a deficit — plus the Debt cards), Poverty & Inequality (Monetary Poverty, Extreme Poverty and Gini, built by a local `_poverty_cfg(cfg)` helper — all three are rates where lower is better, reported as an absolute delta; Monetary Poverty also appears as the 5th Headline Indicator), and Demographics.

**Data flow:**
1. CSVs in `data/` → read by page/tab files → cleaned/pivoted by the per-domain helpers (`pages/helpers/macro/` for `gdp_functions.py`/`cpi_functions.py`/`job_market_functions.py`; `pages/helpers/demography/` for `births_functions.py`/`deaths_functions.py`/`migration_functions.py`/`population_functions.py`) → charted by `pages/helpers/charts.py` (all Plotly builders, generic + population-only, shared by all three pages)
2. Raw data comes from five sources: **DANE** (National Statistics Dept), **Banco de la República** (Central Bank), **World Bank** (net migration), **Migración Colombia** (inbound/outbound travelers, stored under `datos_abiertos/`), and **Ministerio de Hacienda** (public debt)

**Translation pattern:** Each GDP perspective has a matching dict in `generalities/macro_generalities/gdp_spend.py` (or `gdp_production.py`, `gdp_income.py`). The dict key is the Spanish `Concepto` value in the CSV; the value is the English label shown in the UI. `gdp.py` dynamically resolves which dict to use via `getattr(t, f"spend_{file}_terms", None)`.

**President filter:** `presidents` dict maps name → list of years (integers); `get_valid_presidents` intersects the data's year range with these. The UI is now a multiselect (`president_multiselect`): selecting one president filters years to `presidents[name]`; selecting two or more enters **comparison mode**, where `reshape_by_presidents` (`generalities/function.py`) re-indexes data to a relative "Term Year" axis and emits one column per variable×president. Used across Macroeconomics (GDP, CPI) and Demography (National/Department/Municipality/Migration/Births/Deaths).
