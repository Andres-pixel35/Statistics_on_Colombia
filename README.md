# Statistics on Colombia

**Statistics on Colombia** is an open-source project that presents Colombian
statistics in a simple, interactive way — GDP, CPI (inflation), labor market,
productivity, public debt, deficit, poverty, and population (births, deaths,
and migration) and more.

## Live demo

- **App:** https://statisticsoncolombia.streamlit.app/
- **Instagram:** https://www.instagram.com/statisticscolombia/

## Status

Feature development is complete; data is kept up to date with the latest
releases from each source. Available in **English only** for now — a Spanish
version is the current focus.

## Tech stack

- **Streamlit** — hosts the app and renders the interactive charts
- **Python** + **pandas** — data cleaning and manipulation
- **Plotly** — charting

## Data sources

- **DANE** — Colombia's National Administrative Department of Statistics
- **Banco de la República** — Colombia's central bank
- **World Bank** — net migration
- **Migración Colombia** — inbound/outbound travelers
- **Datos Abiertos Colombia** - Colombia biggest plataform to access and download data
